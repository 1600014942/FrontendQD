# 视觉系统

## 字体

- 中文界面、标题与正文：`PingFang SC` 优先，依次回退至 `PingFang TC`、`Hiragino Sans GB`、`Noto Sans CJK SC`、`Microsoft YaHei`。
- 英文、数字、标签：`DIN Alternate` 优先，依次回退至 `DIN Condensed`、`Arial Narrow`。
- 全站不使用楷体、宋体或其他中文衬线字体；不打包或分发字体文件。

## 色彩

- 主背景：`#F7F6F2`；
- 辅助背景：`#FAF9F6`；
- 主文字：`#111111`；
- 次级文字：`#6D6D69`；
- 边框：`rgba(17,17,17,0.13)`；
- 全站维持黑、白、灰，不增加额外品牌色。

## 尺度

- 桌面最大内容宽度：`1680px`；
- 基准桌面：`1920 × 1080`；
- 首页章节：桌面最小高度 `100vh`，移动端改为内容驱动；
- 导航高度：桌面 `94px`，滚动后 `76px`；移动端 `68px`；
- 线条：通常 `1px`；
- 圆角：仅测算器状态值、评价原资产和必要控件使用小圆角。

## 动效

- 标题和内容进入视口时淡入与轻微上移；
- 球体仅做 8px 范围内的慢速整体漂浮；
- 数字随测算器输入即时平滑更新；
- 客户评价支持拖动、触控和方向键；
- 导航滚动后增加轻微背景模糊与底边线；
- 全站支持 `prefers-reduced-motion`。

## 响应式

- `≥1440px`：接近 PPT 的一屏构图；
- `1024–1439px`：缩小标题和间距，仍保持左右构图；
- `768–1023px`：首屏上下布局，图表可横向滚动，测算器上下排列；
- `375–767px`：移动菜单、指标改为纵向行、球体完整缩放、文章与表单单列。
